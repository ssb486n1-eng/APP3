원인 ① 번역 중 발화 유실
이전 버전은 processingLock으로 번역 API 응답을 기다리는 동안 들어온 문장을 버렸습니다. → 락을 제거하고 문장별 비동기 처리로 변경했습니다.

원인 ② isFinal을 문장 끝으로 오인
안드로이드에서 isFinal/onend는 "말이 끝났다"가 아니라 무음 3~5초 타임아웃입니다. → 이제 세션 종료 시 번역을 확정하지 않고 버퍼를 유지한 채 재시작만 하며, 확정은 무음 타이머·문장부호·최대 길이로만 판단합니다.

원인 ③ TTS 되먹임 루프
번역 음성이 스피커 → 마이크로 재입력되어 재인식·재번역되었습니다. → 음성 출력 중 마이크를 자동 차단합니다.

원인 ⑥ 인식 리비전으로 인한 반복 재발
인식기는 도중에 띄어쓰기·어절을 수정(리비전)해 전체 문장을 다시 보냅니다 (예: "책이야 이" → "책이야이"). 단어 단위 겹침 비교는 여기서 실패해 문장이 통째로 이어붙었습니다. → 공백·문장부호를 제거한 정규화 비교로 "대체/델타"를 구분하고, 자막은 확정 전까지 수정하며 유지되다가 실제 침묵에서만 한 번 확정합니다. 확정 즉시 인식 세션을 리셋해 확정 문장의 재전달을 차단합니다.

원인 ⑤ 누적형 인식 결과 (같은 말 4~6회 반복의 진짜 원인)
안드로이드는 results[0]="나는", results[1]="나는 오늘", results[2]="나는 오늘 공룡" 처럼 매번 전체 문장을 다시 담아 보냅니다. 인덱스 기준으로 새 결과만 이어붙이면 계단식으로 중복됩니다. → 이제 인덱스가 아니라 단어 겹침(overlap) 병합으로 처리하며, 세션 간 재전달 제거와 반복 블록 축약 안전망을 함께 적용합니다.

원인 ④ 좀비 세션
안드로이드가 onend 없이 인식을 죽이는 경우가 있습니다. → 3초 주기 워치독이 감지해 부활시킵니다.

🛡️ Cloudflare Workers 무료 프록시 (DeepL/Google CORS 완전 해결)

DeepL API는 CORS 헤더를 주지 않아 브라우저에서 직접 호출하면 실패합니다. 아래 Worker 하나로 DeepL·Google 모두 프록시하여 CORS를 완전히 없앱니다.

① Cloudflare Worker 배포 (5분)
1
dash.cloudflare.com 가입 → 좌측 Workers & Pages → Create → Create Worker
2
이름 지정(예: translate-proxy) → Deploy → Edit code
3
기본 코드를 모두 지우고 아래 코드를 붙여넣기 → Deploy
4
생성된 https://translate-proxy.내계정.workers.dev 주소를 복사 → 설정의 프록시 URL에 붙여넣고 토글 ON

📄 Worker 코드 (개선판 — 타임아웃·오류전달 추가)

// ===== Cloudflare Workers · DeepL/Google 번역 프록시 (개선판) =====
// 개선점
//  1. AbortSignal.timeout 으로 업스트림 타임아웃 (앱이 무한 대기하지 않음)
//  2. 업스트림 오류 상태코드/본문 전달 (429 쿼터초과 등 진단 가능)
//  3. DeepL split_sentences=nonewlines / preserve_formatting=1
//     → 실시간 조각 번역 시 문장이 임의로 쪼개지지 않음
//  4. 빈 문자열·동일 언어 조기 반환으로 쿼터 절약
const DEEPL_KEY  = "";   // 예: "xxxxxxxx:fx"  (비우면 앱이 보낸 키 사용)
const GOOGLE_KEY = "";   // 예: "AIzaSy..."    (비우면 앱이 보낸 키 사용)

const UPSTREAM_TIMEOUT_MS = 7000;
const MAX_TEXT_LEN = 5000;

export default {
  async fetch(request) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "GET,POST,OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type,Authorization,X-Api-Key",
      "Access-Control-Max-Age": "86400",
    };
    if (request.method === "OPTIONS")
      return new Response(null, { headers: cors });

    const url = new URL(request.url);
    if (request.method === "GET" && url.pathname === "/")
      return json({ ok: true, service: "translate-proxy" }, cors);

    try {
      const body = await request.json();
      const engine  = body.engine;
      const text    = String(body.text || "").slice(0, MAX_TEXT_LEN);
      const source  = String(body.source || "").toLowerCase();
      const target  = String(body.target || "").toLowerCase();
      const context = String(body.context || "").slice(0, 1000);
      const clientKey = request.headers.get("X-Api-Key") || body.key || "";

      if (!text.trim()) return json({ text: "" }, cors);
      if (source && target && source === target) return json({ text }, cors);

      if (engine === "deepl") {
        const key = DEEPL_KEY || clientKey;
        if (!key) return json({ error: "no deepl key" }, cors, 400);
        const isFree = /:fx$/.test(key.trim());
        const host = isFree ? "https://api-free.deepl.com"
                            : "https://api.deepl.com";
        const p = new URLSearchParams();
        p.append("text", text);
        if (source) p.append("source_lang", deeplLang(source, false));
        p.append("target_lang", deeplLang(target, true));
        p.append("split_sentences", "nonewlines");
        p.append("preserve_formatting", "1");
        if (context) p.append("context", context);   // context 문자는 과금되지 않음
        const r = await fetch(host + "/v2/translate", {
          method: "POST",
          headers: {
            "Authorization": "DeepL-Auth-Key " + key.trim(),
            "Content-Type": "application/x-www-form-urlencoded",
          },
          body: p.toString(),
          signal: AbortSignal.timeout(UPSTREAM_TIMEOUT_MS),
        });
        if (!r.ok) {
          const detail = await r.text().catch(() => "");
          return json({ error: "deepl " + r.status, detail: detail.slice(0,300) },
                      cors, r.status === 429 ? 429 : 502);
        }
        const j = await r.json();
        const out = j?.translations?.[0]?.text || "";
        if (!out) return json({ error: "deepl empty", raw: j }, cors, 502);
        return json({ text: out }, cors);
      }

      if (engine === "google") {
        const key = GOOGLE_KEY || clientKey;
        if (!key) return json({ error: "no google key" }, cors, 400);
        const payload = { q: text, target, format: "text" };
        if (source) payload.source = source;
        const r = await fetch(
          "https://translation.googleapis.com/language/translate/v2?key="
            + encodeURIComponent(key.trim()),
          {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify(payload),
            signal: AbortSignal.timeout(UPSTREAM_TIMEOUT_MS),
          }
        );
        if (!r.ok) {
          const detail = await r.text().catch(() => "");
          return json({ error: "google " + r.status, detail: detail.slice(0,300) },
                      cors, r.status === 429 ? 429 : 502);
        }
        const j = await r.json();
        const raw = j?.data?.translations?.[0]?.translatedText || "";
        if (!raw) return json({ error: "google empty", raw: j }, cors, 502);
        return json({ text: decodeEntities(raw) }, cors);
      }

      return json({ error: "unknown engine" }, cors, 400);
    } catch (e) {
      const msg = String(e);
      const to = /Timeout|abort/i.test(msg);
      return json({ error: to ? "upstream timeout" : msg }, cors, to ? 504 : 500);
    }
  },
};

function deeplLang(c, isTarget) {
  const m = { ko: "KO", en: isTarget ? "EN-GB" : "EN", cs: "CS" };
  return m[c] || c.toUpperCase();
}
function decodeEntities(s) {
  return s.replace(/&lt;/g, "<").replace(/&gt;/g, ">")
          .replace(/&quot;/g, '"').replace(/&#39;|&apos;/g, "'")
          .replace(/&nbsp;/g, " ")
          .replace(/&#(\d+);/g, (_, d) => String.fromCodePoint(+d))
          .replace(/&#x([0-9a-f]+);/gi, (_, h) => String.fromCodePoint(parseInt(h,16)))
          .replace(/&amp;/g, "&");   // 반드시 마지막
}
function json(obj, cors, status = 200) {
  return new Response(JSON.stringify(obj), {
    status,
    headers: { ...cors, "Content-Type": "application/json",
               "Cache-Control": "no-store" },
  });
}
✅ 이 앱은 프록시로 POST { engine, text, source, target, context, key } 형식으로 요청합니다. 위 코드는 이 형식을 그대로 처리하므로 수정 없이 바로 동작합니다.
